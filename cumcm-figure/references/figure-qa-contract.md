# 配图交付终检（figure-qa-contract）

**这是交付前唯一必须逐条走完的清单。** 出图脚本跑通不等于图能读；图能读不等于合规。
国赛的两级评阅里，第一级（赛区）淘汰率最高，而图是评委第二遍阅读时最先落眼的东西——
一张糊图、一张没有结论的图、一处出现在图里的校名，代价可能是整篇论文。

> **使用时机**：每次 `save_cumcm_figure` 之后、把图插进 `paper/manuscript.tex` 之前，以及 P15 红队审稿时。
> **三条前置**：① 图契约（`figure-contract.md`）已填；② 导出的 **PDF 已经用 100% 缩放打开看过**；
> ③ 图注草稿已写好（`figure-caption.md`）。

---

## 1. 结论与证据

| 检查项 | 通过条件 | 怎么查 |
|---|---|---|
| 一句话结论 | 能对着图说出"这张图证明了 X 比 Y 低 6.2%"，带动词、方向、数字、对照 | 念给没参与绘图的队友听，他能复述出来 |
| 每面板独有证据 | 逐个面板问"盖住它，论证会变弱吗？"答"不会"的必须合并或删除 | 对着契约的"面板映射"逐条核 |
| 绑定 C0x | 每个承载数值的面板都绑到 `claim_ledger.md` 里"可写入论文 = 是"的 C 编号 | `grep -n "C0" sop/project/claim_ledger.md` 对照 |
| 有对照对象 | 出现"更优/更低/更好"时，图上必有被击败的基线 | 数曲线/柱子的组数：只有一组 = 缺对照 |
| 结论不超边界 | 图上措辞的强度 ≤ 账本原文；不宣称超出"适用边界"的范围 | 把账本那行结论与图注并排读一遍 |

## 2. 可读性

| 检查项 | 通过条件 | 怎么查 |
|---|---|---|
| 最终尺寸下最小字号 | 打印后刻度 ≥ 7.5pt、轴标签 ≥ 8.5pt（见 `design-theory.md` §1.2） | 打开 PDF，缩放到 **100%**（不是"适合页面"），在屏幕上量 —— 屏幕上 100% 显示的字高 ≈ 纸面字高 |
| 中文正常 | 无方框、无缺字、无回退成宋体的混排 | `apply_cumcm_style()` 已挑本机真实字体；打开 PDF 目视 |
| 负号正常 | 负号是短横线而不是 `□` | `axes.unicode_minus=False`（`apply_cumcm_style` 已设）；看一张含负值的图 |
| 图例不遮数据 | 图例、统计框、`n` 标注都不压在数据点上 | 目视；统计信息用 `add_stat_box`（画在轴上方，不占绘图区） |
| 标注不压线 | 峰值/最优点/约束边界的标注与箭头不覆盖曲线 | 目视；`annotate_extremum` 的 `xytext` 逐张调 |
| 单位齐全 | 每根轴都是"量名 / 单位"；色标也一样 | 逐轴读一遍：`投放时刻 $t_1$ / s` ✅，`t1` ❌ |
| 刻度可读 | 刻度落在整数或易读值；不出现 `0.003333` 这类刻度 | 必要时 `ax.set_xticks([...])` 手工指定 |
| 无遮挡性溢出 | 轴标签、图例、面板标签都在 `bbox_inches="tight"` 后被完整包含 | 看 PDF 边缘有没有被切掉的半个字 |

## 3. 数值诚信（这一节失分最隐蔽，也最致命）

| 检查项 | 通过条件 | 反例与处置 |
|---|---|---|
| **坐标轴是否被截断而误导** | 柱状图 y 轴**必须从 0 起**；折线图可以截断，但必须满足：① 截断是为了看清趋势而非放大差异；② 图注写明"纵轴自 38500 元起"；③ 轴上画断轴记号 | 反例：成本 38650 vs 41000 的两根柱，y 轴从 38500 起 → 视觉上"高了 3 倍"，实际只差 6.2%。这是**数值误导**，评委一句话就能打掉 |
| **双轴是否误导** | 左右轴零点已对齐，或两条曲线有明确因果并被图注写明；两侧轴颜色与曲线颜色一致 | 反例：左轴成本从 0 起、右轴定价从 30 起 → 读者会以为"成本涨得快"。见 `chart-families.md` §2.2，优先改共享 x 轴的上下子图 |
| **n 与误差定义是否标注** | 图注或 `add_stat_box` 里出现：n、误差棒/区间的含义（标准差/标准误/置信区间/极差）、重复次数与随机性来源 | 反例：画了误差棒但全文没说它是什么。评委对**未定义的误差棒**比对没有误差棒更反感 |
| 对数轴是否标注 | 用 `set_yscale("log")` 时，轴上或图注写明"纵轴为对数刻度" | 反例：对数轴让读者以为是线性增长 |
| 平滑/插值是否声明 | 做了插值、平滑、拟合的曲线，图注写明方法与点数 | 反例：`splrep` 平滑后画出真实数据里不存在的振荡，等于造假 |
| 颜色映射是否截断 | `vmin/vmax` 偏离数据极值时必须说明（"色标截断于 ±20%，超出部分取端点色"） | 反例：截断色标让所有值看起来"都在范围内" |
| 面积/气泡是否成比例 | 用面积编码数值时，半径 ∝ √数值（不是 ∝ 数值） | 反例：半径正比于数值 → 面积被平方放大 |
| 是否只报最优不报分布 | 启发式/仿真题必须给多次运行统计（均值 ± 标准差、极差、命中率） | 反例："遗传算法求得最优值 12.7"（单次运行无统计意义） |
| 是否抽样取景 | 挑了一个好看的时段/子集时必须写明 | 反例：只画 18:00–22:00 的 SOC 曲线却不说是子集 |

**一条总判据**：把自己当成恶意评委，问一句——**"这张图有没有让某个差异看起来比真实的大（或小）？"**
任何"是"的答案，都必须用断轴记号、零点对齐、子图拆分或图注声明来消解。

## 5. 导出质量

| 检查项 | 通过条件 | 怎么查 |
|---|---|---|
| 矢量优先 | 线条/柱/散点/箱线类图**只放 PDF**；热力图/等值线/3D 加 `set_rasterized(True)` | `save_cumcm_figure` 默认同时产出 PDF 与 600dpi PNG |
| 位图 dpi | 位图 ≥ 600 dpi（`savefig.dpi = 600`，`save_cumcm_figure` 固定用 600） | 看 PNG 属性或 `fig.dpi` |
| 字体嵌入 | PDF 里文字**可选中、可搜索** | `pdffonts x.pdf` 的 `em` 列为 `yes`；或跑 `figure_check.py`（见 §9）；无 poppler 时用 §9.2 的片段 |
| 体积 | 单图 PDF ≤ 1.2 MB；`results/figures/` 累计 ≤ 12 MB；最终论文 PDF ≤ 20 MB（规则 `R-FILES`） | `save_cumcm_figure` 返回的字节数 + `figure_check.py` 的体积预算项（见 §9） |
| 打开看过了 | 用 100% 缩放看过 PDF，不是只看 IDE 预览或 PNG | 这一步**不可跳过**——"代码跑通了"不等于"图能读" |
| 灰度/黑白可读 | 转灰度后每一条曲线、每一类柱子仍可区分 | `Image.open(png).convert("L")`，见 `design-theory.md` §3.3 |

> **关于自动化的实话**：本仓库已实现 `../scripts/figure_check.py`，它会自动检查
> **字体嵌入、图内与文件名身份信息、近空图、体积预算、矢量/位图是否成对、命名规范**，
> 并输出 `logs/figure_check.txt`。用法：
>
> ```powershell
> python skills\cumcm-figure\scripts\figure_check.py --dir results\figures
> python skills\cumcm-figure\scripts\figure_check.py --pdf paper\manuscript.pdf
> ```
>
> 导出期还有一层防护：`save_cumcm_figure` 会统计每张图的**数据元素数量**，
> 整张图没有任何数据元素时告警（空图防护）。注意这一层不能用文件大小替代——
> 实测矢量 PDF 里"只有坐标轴"（2041 B）与"200 个数据点"（4065 B）体积几乎相同。
>
> **仍需人工判断的**：字号是否够大、留白是否合理、图例是否遮挡数据、结论是否一眼可见。
> 这些靠 `figure_check.py` 查不出来，必须**打开 PDF 用 100% 缩放看一遍**。

## 6. 合规（取消评奖资格项，逐张图都必须过）

| 检查项 | 通过条件 | 依据 |
|---|---|---|
| **图中无校名** | 图内文字、图例、标注、水印、软件界面截图里都不出现学校名称 | `R-IDENTITY`：摘要页、正文、附录**任何地方**都不得出现参赛者身份、所在学校及赛区信息 |
| **图中无姓名/学号** | 无队员姓名、学号、昵称、`@author` 残留 | 同上 |
| **图中无赛区信息** | 无省份/赛区名、无赛区编号 | 同上 |
| **无校徽/机构 Logo** | 含 Logo 的截图必须裁掉或重绘 | 同上 |
| **软件截图已净化** | MATLAB/Origin/SPSS 界面截图里的用户名、License 持有机构、文件绝对路径已裁掉或重绘 | 同上——这是最常被忽略的一条 |
| **图片元数据已清** | PNG/JPEG 的 EXIF/XMP 里无作者与设备信息 | 进 PDF 前用 `PIL` 重存一次即可剥离 |
| **无第三方版权素材** | 地图、网络图片、教材插图已注明来源或替换为重绘图 | `R-CITE`：引用他人或公开资料必须按规范列出并标注 |
| **图题在图下方** | `\caption` 写在 `\includegraphics` **之后**（表格相反） | 与三线表规范配套 |

**一条硬事实**：出现身份信息是**取消评奖资格**项，不是扣分项。所以这一节的检查对象不只是正文，
而是**每一张图、每一个截图、每一份导出的 PDF 元数据**。

## 9. 可执行的检查

### 9.1 首选：跑 `figure_check.py`（已实现，覆盖本文 §4–§6 的机器可查部分）

```powershell
python skills\cumcm-figure\scripts\figure_check.py                       # 默认查 results/figures 与 sop/project/figures
python skills\cumcm-figure\scripts\figure_check.py --dir results\figures
python skills\cumcm-figure\scripts\figure_check.py --pdf paper\manuscript.pdf   # 顺带查论文里的图与身份信息
```

它检查：PDF+PNG 是否成对、体积预算、字体嵌入、位图分辨率与图高宽比、
**图内文本与文件名里的身份信息**（校名/学院/学号/赛区/本机绝对路径）、命名是否为 `E0x_` 前缀、
近空图；报告写到 `logs/figure_check.txt`。

它**查不出来**的四件事，只能人工看：**字号够不够大、留白是否合理、图例是否遮挡数据、结论是否一眼可见。**
这四项正是本文 §2 与 §10 存在的理由。

### 9.2 兜底片段（`figure_check.py` 不可用时，或补查灰度可读性）

```python
"""配图导出后的机器可查部分：体积、文字可提取（⇒ 字体已嵌入）、灰度可读。"""
from pathlib import Path
from pypdf import PdfReader
from PIL import Image

FIGS, SINGLE_BUDGET, TOTAL_BUDGET = Path("results/figures"), 1_200_000, 12_000_000

# ① 体积：单图 + 累计
total = sum(p.stat().st_size for p in sorted(FIGS.glob("*.pdf")))
for p in sorted(FIGS.glob("*.pdf")):
    n = p.stat().st_size
    print(f"[{'OK ' if n < SINGLE_BUDGET else 'OVER'}] {p.name:38s} {n/1024:8.0f} KB")
print(f"[{'OK ' if total < TOTAL_BUDGET else 'OVER'}] 累计 {total/1e6:.2f} MB / {TOTAL_BUDGET/1e6:.0f} MB")

# ② 字体嵌入 + 中文可提取（文字能提取 ⇒ 字体是文本而非路径，且已嵌入）
for p in sorted(FIGS.glob("*.pdf")):
    txt = "".join(pg.extract_text() or "" for pg in PdfReader(str(p)).pages)
    print(f"{p.name:38s} 中文可提取={any(chr(0x4e00) <= ch <= chr(0x9fff) for ch in txt)}")

# ③ 灰度可读性（figure_check.py 不查这一项）：生成灰度副本，人工看一眼能否分辨各系列
for p in sorted(FIGS.glob("*.png"))[:3]:
    Image.open(p).convert("L").save(p.with_name("_gray_" + p.name))
```
