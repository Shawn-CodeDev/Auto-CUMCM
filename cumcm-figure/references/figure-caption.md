# 图题与图注（figure-caption）

图注是**图的说明书，不是图的旁白**。国赛评委第二遍阅读时先看图、再读图注——
图注没写清 n 与单位，他不知道这个数字能不能信；图注写不出方法，他无法判断这图是不是套模板画的。

> 本仓库模板的相关设置（`templates/cumcm-thesis/cumcm2026.sty`）：
> `\captionsetup{font=small,labelsep=quad,skip=6pt}`、`\renewcommand{\figurename}{图}`。
> 因此 `\caption{问题二的最优调度方案}` 会渲染成 **"图 3　问题二的最优调度方案"**。

---

## 1. 图题格式

### 1.1 五条硬规范

1. **图题在图的下方**（`\caption` 写在 `\includegraphics` 之后）。**表题在表的上方**——两者相反，
   这是科技论文的通用规范，模板已用 `\captionsetup[table]{position=top}` 固定表格侧，图侧由你写的位置决定。
2. **中文图题**。专有名词可保留英文（NIPT、SEM、ARIMA、MPC、MILP），但句子结构是中文。
3. **不要在 `\caption{}` 里手写"图 3"**。模板已经生成"图 N"前缀（`labelsep=quad` 给出那个空档），
   手写会变成"图 3　图 3 ..."。
4. **编号用 `\label` + `\ref`，禁止手写编号**：
   ```latex
   \caption{问题二的最优购电与储能调度方案}\label{fig:q2-plan}
   ... 如图~\ref{fig:q2-plan} 所示 ...      % 波浪号 ~ 防止"图"与数字之间断行
   ```
5. **编号方式全文统一**。模板默认是全文连续编号（图 1、图 2…），**推荐直接用默认**，不要加
   `\numberwithin{figure}{section}` 去改成"图 3-1"——多一事多一处出错。

### 1.2 三段式结构

```text
图 N  <短标题：这张图画的是什么>          ← 必填，≤20 字，末不加标点（全文统一）
      <方法与数据说明：单位、n、误差定义、方法简称>   ← 定量图必填
      (a) …；\ (b) …。                    ← 多面板必填
```

### 1.3 图内标题 vs 图题

**不要在图内再写一遍标题。** `ax.set_title("图 3 各方案成本对比")` 会造成两个问题：
① 与 `\caption` 重复，浪费纵向空间；② 一旦 LaTeX 编号变化（插入了新图），图内文字就成了错的编号。
图内只允许极短的面板定位词（"成本"、"SOC"、"电价"），字号取 `mpl.rcParams["font.size"]`，不加粗。

## 2. 图注要素：五件必写 + 两件按需

| 要素 | 什么时候必须写 | 写法示例 |
|---|---|---|
| **单位** | 图上任何带数值的轴、色标、标注 | 轴标签用"量名 / 单位"：`全天购电成本 / 元`；图注里也可补一句口径 |
| **n** | 有任何统计量（均值、区间、误差棒、拟合） | `n = 144 个时段（Δt = 10 min）`、`20 次独立运行` |
| **误差棒/区间的定义** | 图上出现误差棒、置信带、箱体、阴影 | `误差棒为 20 次独立运行的标准差`、`阴影为 5 个随机种子的取值范围` |
| **方法简述** | 图是由某个算法/模型产出的 | `由混合整数线性规划求得（0-1 变量刻画充放电互斥）` |
| **数据来源** | 定量图 | `数据来自 E02（results/main/E02/q2_plan.csv）` |
| **显著性说明**（按需） | 做了假设检验 | `两组差异经 Wilcoxon 秩和检验，p = 0.003 < 0.05` |
| **适用边界**（按需） | 结论只在某范围内成立 | `该结论在电价峰谷比 ≤3.5 时成立` |

**反面清单**：缺单位、缺 n、误差棒没定义——这三项是国赛图注里最常见的三处失分，且都能被评委一句话问倒。

### 2.1 每个要素在代码里的落点

图注写不出来的根因往往不是文字，而是图上缺东西。对着下表逐个补：

| 图注要素 | 代码落点 |
|---|---|
| 单位 | `ax.set_xlabel("全天购电成本 / 元")`、`fig.colorbar(im, ax=ax, label="有效遮蔽时长 / s")` |
| n 与误差定义 | `add_stat_box(ax, "n = 144 时段，Δt = 10 min；误差棒为 5 个随机种子的极差")`（画在轴**上方**，不占绘图区） |
| 方法简述 | 图注文字本身；数据来源写进图的元数据/契约，不必画在图上 |
| 关键点数值 | `annotate_extremum(ax, t[i], T[i], "峰值 1.85 s")`（最优解必须一眼可见） |
| 面板标签 | `panel_label(ax, "a")`，与图注里的 `(a) …` 一一对应 |
| 数据来源与体积 | `save_cumcm_figure(fig, "results/figures/E02_q2_dispatch")` 返回各文件字节数，可写进图注的来源行 |

## 3. 三种长度的图注模板

### 3.1 单句图注（≤1 行，约 30 字）

**适用**：自明的示意图、单一曲线、算法流程图。

```latex
\caption{本文的建模与求解总体框架}\label{fig:framework}
```

```latex
\caption{差分进化算法的收敛曲线}\label{fig:conv}
```

**注意**：单句不等于可以缺信息。如果图里出现了两个以上的量、任何统计量，就必须升级到标准图注。

### 3.2 标准图注（2–3 行，60–120 字）

**适用**：结果对比图、灵敏度图、分布图、绝大多数定量图。

```latex
\caption{三种购电方案的全天成本对比。基线为纯线性规划方案与现行分时购电方案，
本文方案引入储能充放电互斥约束。$n=144$ 个时段（$\Delta t=10$~min），
确定性求解；误差棒为 5 个随机种子的最大相对漂移（$0.4\%$）。
数据来自 E03（\texttt{results/main/E03/cost\_compare.csv}）。}
\label{fig:cost-compare}
```

四句话的结构：**画的是什么 → 对照是谁 → n 与误差 → 数据来源**。

### 3.3 组合图图注（3–5 行，120–200 字）

**适用**：多面板组合图。额外的第一句是"总述"，之后逐面板说明。

```latex
\caption{问题二的最优购电与储能调度方案。(a) 全天 144 时段的功率平衡，
其中紧急购电在全天恒为 0；(b) 储能荷电状态轨迹，阴影为允许区间
$[1200,\ 10800]$~kWh，起止值均为 6000~kWh；(c) 三种方案的全天购电成本对比；
(d) 电价峰谷比、储能效率、寿命损耗系数、储能容量在 $\pm20\%$ 扰动下
对成本的影响。$n=144$ 个时段（$\Delta t=10$~min），确定性 MILP 求解，
误差来自 5 个随机种子的最大漂移 $0.4\%$。(a)(b) 来自 E02，(c) 来自 E03，(d) 来自 E05。}
\label{fig:q2-plan}
```

**排列纪律**：面板说明的顺序必须与图内 `(a)(b)(c)` 标签的顺序**完全一致**，
且每个面板说明都以它"要看出的什么"结尾，而不只是"画的是什么"。

## 4. 六个真实感的图注范例

### 4.1 结果对比图（分组柱 + 基线）

```latex
\caption{问题二三种方案的全天购电成本对比。纵轴自 0 起；柱顶标注绝对成本，
柱间标注相对基线的变化率。基线为 P9 的纯线性规划方案。$n=144$ 个时段
（$\Delta t=10$~min），确定性求解；误差棒为 5 个随机种子的最大相对漂移
（LP 基线 $0.0\%$、本文方案 $0.4\%$）。数据来自 E02、E03。}
\label{fig:q2-cost}
```

**它为什么合格**：声明了"纵轴自 0 起"（预先消解截断质疑）、给了 n、定义了误差棒、说清了基线是谁。

### 4.2 灵敏度图（龙卷风图）

```latex
\caption{关键参数在 $\pm20\%$ 扰动下对全天购电成本的影响（基准方案成本
38650 元，见 C01）。条形长度为目标值相对基准的变化率，按影响绝对值降序排列；
正负方向分居零线两侧。各项均为单因素（OAT）扰动，参数间交互效应未计入。
$n=144$ 个时段；每个参数 4 档扰动共 16 次确定性求解。数据来自 E05
（\texttt{results/main/E05/sens.csv}）。}
\label{fig:tornado}
```

**它为什么合格**：写明了基准值与来源结论编号、排序规则、**单因素分析的局限**（预答"你考虑交互了吗"）。

### 4.3 机理示意图（微网能量流）

```latex
\caption{微网与外部电网的能量流关系。光伏优先供给本地负载，盈余电量经变流器
存入储能；当负载超过光伏出力时由储能放电补充，仍不足时向外部电网购电，
极端情况下触发紧急购电（电价为同时段交易电价的 5 倍）。箭头粗细表示功率量级，
数值为基准工况下的典型值。本图为示意图，不承载独立数值证据；
参数取自附录 1。}
\label{fig:microgrid-flow}
```

**它为什么合格**：示意图也必须写"不承载独立数值证据"（否则会被追问实验编号），
并交代参数来源；数值明确标注为"典型值"。

### 4.4 收敛曲线

```latex
\caption{差分进化算法的收敛过程。实线为 20 次独立运行中的最好一次，
虚线为最差一次，点线为线性规划松弛下界。算法在第 262 代满足终止判据
（连续 40 代改进量 $<10^{-4}$），最好与最差解的相对极差为 $0.4\%$，
与松弛下界的相对间隙为 $1.0\%$。$n=20$ 次独立运行（\texttt{seed}=0--19）。
数据来自 E02。}
\label{fig:convergence}
```

**它为什么合格**：明确了"收敛到什么精度"、"用了多少步"、"稳定性如何"、"离下界多远"——
这四件事正是 `solution_and_validation.md` 要求的。只写"程序收敛了"等于没写。

### 4.5 网络图（路径 / 定位类）

```latex
\caption{区域路网与本文求得的最短巡检路径。节点为 20 个巡检点，
坐标为题目附表给定的平面坐标（单位：km），边权为欧氏距离；
粗线为 Dijkstra 算法求得的最短路径，总长度 $3.575$~km。
灰色细线为其余可行路段。图中标注了起点 $S$ 与终点 $T$。
数据来自 E04（\texttt{results/main/E04/route.csv}）。}
\label{fig:route}
```

**它为什么合格**：给了坐标系与单位、算法名、路径长度数值、节点数（相当于 n）、数据来源。
**常见缺项是路径长度**——网络图里没有数值，等于只有一张"好看的毛线球"。

### 4.6 三维场图（温度场 / 空间分布）

```latex
\caption{热风干燥箱内料层温度场的空间分布。$x$、$y$ 为箱体横向坐标（单位：m），
$z$ 为料层高度（单位：m）；色标为温度（单位：$^\circ$C），由 Crank--Nicolson
格式求解二维热传导方程得到（$N=80$ 网格，$\Delta t=6.25\times10^{-5}$~s，
经 $N=20,40,80,160$ 四组网格验证为二阶收敛）。等值线间隔 $2~^\circ$C，
红星为温度最高点（$68.4~^\circ$C，位于进风口正下方）。数据来自 E06。}
\label{fig:temp-field}
```

**它为什么合格**：三维图最容易被评委问"你为什么不用等高线"——所以图注里把
**网格、步长、收敛阶**都写出来（证明数值可信），并直接标出峰值与位置（让读数不需要靠眼睛）。

## 5. 面板说明的写法

### 5.1 格式

- 标签用**半角小写字母 + 半角括号**：`(a)`（与 `panel_label()` 的输出一致），全文统一；
  不要混用 `a)`、`A`、`（a）`（全角括号）。
- 每个面板说明的结构：**`(a) <画的是什么>，<要看出的什么>；`**
- 面板之间用**分号**分隔，最后一个面板后用**句号**。整段连排，**不要在 `\caption{}` 里用 `\\` 换行**
  （在某些宏包组合下会报错；长图注让 LaTeX 自己折行）。
- 面板说明里的量名、单位、符号写法必须与正文、图内标签三处一致（`t_1` 不能在图注里变成 `T1`）。

```latex
(a) 全天 144 时段的功率平衡，其中紧急购电恒为 0；
(b) 储能荷电状态轨迹，全程落在允许区间内且起止相等；
(c) 三种方案的成本对比，本文方案较基线低 $6.2\%$；
(d) 关键参数 $\pm20\%$ 扰动对成本的影响，电价为主导因素。
```

### 5.2 面板说明与图内标签的对应关系（只选一条路）

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（国赛推荐）** | 图内用 `panel_label(ax, "a")` 打标签；图注里手写 `(a) … (b) …` | 无自动化编号，改图序时要手改图注 |
| B | 图内不打标签；用 `subcaption` 环境的 `\subcaption{}` 自动编号 | 会生成"图 3a"式的子编号，且图注里再写 `(a)` 就重复了 |

**两条路不能同时走**。同时用会渲染出"图 4a　(a) 全天功率平衡"这种双重编号，
这是 P15 红队一眼就能抓到的表述硬伤。

## 6. 常见图注错误

| # | 错误 | 症状 | 为什么致命 | 改法 |
|---|---|---|---|---|
| 1 | **只说"如图所示"** | 图注写"各方案对比如图所示" | 零信息。图注的功能是让读者不看正文也能读懂 | 补：画的是什么 + 对照是谁 + n + 误差定义 |
| 2 | **没有单位** | 轴上写"成本"、图注不提口径 | 38650 是元、万元还是元/日？无法判断量级 | 轴标签写"量名 / 单位"，图注补口径 |
| 3 | **没有 n** | 有均值/误差棒却不写样本量 | 评委无法评估统计可靠性 | 补 `n = 144 个时段` / `20 次独立运行` |
| 4 | **误差棒没定义** | 画了误差棒，全文不说它是什么 | 比不画误差棒更糟 | 图注写"误差棒为 20 次独立运行的标准差" |
| 5 | **把结论写进图注，抢了正文的活** | 图注写"本文方案显著优于所有基线，证明模型有效" | 图注一旦承担论证，正文的"结果分析"就无话可说；而评委是按正文给分的 | 图注写"是什么 + 怎么看"；正文写"说明什么 + 为什么"（见 `paper_writing.md` §6.5） |
| 6 | **图题与图内标题重复** | 图内 `title` 又写了一遍"图 3 …" | 浪费空间；编号错位风险 | 删图内长标题，只留短的面板定位词 |
| 7 | **手写图号** | `\caption{图 3 各方案成本对比}` | 渲染成"图 3　图 3 各方案…"；插入新图后编号全错 | 删掉手写的"图 N"，用 `\label`/`\ref` |
| 8 | **英文图题** | `\caption{Cost comparison of three schemes}` | 国赛要求中文图题 | 改中文，专有名词可保留英文 |
| 9 | **缩写未展开** | 图注出现 `MPC`、`SOC` 而正文首次出现处没展开 | 评委要回翻 | 首次出现写全称（`模型预测控制（MPC）`），或与符号表一致 |
| 10 | **面板说明与图内标签不对应** | 图内是 `(a)(b)(c)`，图注从 `(b)` 开始写；或 `subcaption` 与手写 `(a)` 并存 | 读者对不上号，直接扣表述分 | 逐面板核对顺序与个数 |
| 11 | **图注过长（>6 行）** | 图注占了半页 | 说明图本身没画清楚，或这段内容属于正文 | 把方法细节移进正文，图注只留"读图必需"信息 |
| 12 | **单位/量名格式错** | 写成斜体单位 `1.85 s`（s 斜体），或量名用正体 | 与 `paper_writing.md` §8.4 的排版规范冲突，显得没检查过 | 单位用 `\mathrm{}` 或 `siunitx`：`$T_1 = 1.85~\mathrm{s}$`；变量用斜体 |
| 13 | **数据来源缺失** | 图注不提 E 编号与数据文件 | 证据链断在最后一步，P15 会按致命问题处理 | 补 `数据来自 E03（results/main/E03/cost_compare.csv）` |
| 14 | **图注里的数字与正文/表格不一致** | 图注写"降低 6.2%"，表 3 写"6.20%"，摘要写"6%" | 数字口径不统一是硬伤 | 统一到 `claim_ledger.md` 第 5 节的"数字口径统一"表 |

## 7. 写完图注后的 30 秒自检

1. 遮住正文，只读图 + 图注：**能说出这张图证明了什么吗？**
2. 把图注里的每个数字圈出来，逐个问"它有单位吗？它和表 3、摘要里的一致吗？"
3. 把图注里的每个面板说明念一遍，对照图内的 `(a)(b)(c)`：**个数和顺序都对得上吗？**
4. 数一遍行数：超过 6 行就往下砍——砍掉的内容要么进正文，要么说明图该重画。
